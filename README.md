# 🔍 KeenKeeper

KeenKeeper is a sophisticated **Personal Interaction Tracker** designed to help users monitor and analyze their social engagements. By documenting various types of interactions—Calls, Texts, and Video Chats—KeenKeeper provides valuable insights into friendship dynamics through a clean, intuitive, and data-driven interface.

---

## 🚀 Technologies Used

The project is built with a modern tech stack focused on performance, responsiveness, and data visualization:

- **Frontend:** [React.js](https://reactjs.org/) (Vite)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [DaisyUI](https://daisyui.com/)
- **Data Visualization:** [Recharts](https://recharts.org/)
- **Routing:** [React Router Dom](https://reactrouter.com/)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
- **State Management:** React Context API

---

## ✨ Key Features

### 1. **Friendship Analytics (Data Visualization)**
Transform raw interaction data into visual insights. KeenKeeper uses interactive **Pie Charts** to categorize and display the distribution of communication methods (Calls, Texts, and Videos), allowing users to see at a glance how they spend time with their friends.

### 2. **Dynamic Interaction Timeline**
A comprehensive history of all social activities. The timeline includes powerful **Filtering and Sorting** capabilities:
- **Search:** Quickly find specific friends or interaction types.
- **Filter:** View only Calls, Texts, or Video chats.
- **Sort:** Organize interactions by date to track recent activities.

### 3. **Responsive & User-Centric Design**
Optimized for every device. Whether you are on a **mobile, tablet, or desktop**, the interface adapts seamlessly. It features a modern "Glassmorphism" aesthetic with smooth animations and a clear hierarchy, ensuring a premium user experience while navigating through stats and logs.
